# Elite Electric - Premium Electrical Solutions

This is a professional, multi-page web application for Elite Electric, a premier distributor of high-quality electrical products.

## Project Structure

- `src/assets/images/`: Highly optimized product images.
- `src/assets/styles/style.css`: Main styling with modern CSS practices.
- `src/js/main.js`: Core interactivity and UI logic.
- `index.html`: Homepage.
- `about.html`: Company history and vision.
- `wire.html`, `switches.html`, `mcb.html`, `light-holders.html`: Detailed product pages.
- `vite.config.js`: Multi-page build configuration.

## Development

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
